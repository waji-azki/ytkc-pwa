# 配信感想メモ (Android向けPWA)

YouTubeアプリの「共有」メニューからこのアプリを選ぶだけで、再生時刻付きの感想を記録できるWebアプリです。
たまったコメントは、あとでふせったーやDiscordに貼れる形式のテキストにまとめて出力できます。

## できること

- YouTubeアプリの共有メニューからこのアプリを開くと、共有された時点の再生時刻を自動で読み取る
- 絵文字ワンタップ・短いテキスト・「コメントなしで位置だけ記録」の3通りで低コストに記録
- 動画ごとに最後に記録した再生位置を自動保存(「前回はここまで視聴」を表示、続きへのリンクつき)
- 動画ごとのログをチャット風に一覧表示、タイムスタンプをタップでYouTubeの該当時刻にジャンプ
- ログをまとめて送信用テキストに整形し、コピーまたは端末の共有機能でDiscord等に直接渡せる
- データは端末内(localStorage)に保存(PCの拡張機能とは連携しません。今回はAndroid中心の運用という前提です)

## 導入手順(重要:HTTPS配信が必須です)

Web Share Target(共有メニューに出す機能)とPWAのインストールには、**HTTPSで配信されたページ**である必要があります。`file://`で直接開いても動作しません。個人利用なら以下のような無料の静的ホスティングで配信するのが手軽です。

1. このフォルダ一式を GitHub のリポジトリにアップロードする
2. リポジトリの Settings → Pages で公開する(GitHub Pagesは自動でHTTPSになります)
   - もしくは Netlify / Vercel / Cloudflare Pages にこのフォルダをそのままドラッグ&ドロップでデプロイしてもOKです
3. 発行されたURL(例: `https://your-account.github.io/ytkc-pwa/`)にAndroidのChromeでアクセスする
4. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ
   - **これを行わないと共有メニューに出てきません**(通常のブラウザタブとして開いているだけでは共有先の候補になりません)

## 使い方

1. YouTubeアプリでアーカイブを再生しながら、感想を書きたい瞬間に「共有」ボタンを押す
2. 共有先の一覧から「感想メモ」を選ぶ
3. このアプリが開き、動画と(取得できれば)再生時刻が自動で入った状態で表示される
4. 絵文字をタップ、またはテキストを入力して送信
5. 見返したいときはアプリを開いて動画を選ぶと、これまでの感想がログとして並ぶ
6. 「送信用テキストを作成」でふせったー/Discord用にまとめて、コピーまたは共有

## 現状の制約(正直に書いておきます)

- **YouTubeアプリの共有リンクに再生時刻が含まれるかは機種・アプリのバージョン依存**です。時刻が付かない共有だった場合は、アプリ側で手動で mm:ss を入力・修正できるようにしています。
- 共有してこのアプリが開いたあと、**YouTubeアプリに自動で戻ることはできません**(Web標準にその手段がないため)。アプリ切り替え操作で手動で戻る形になります。
- 字幕の抜粋添付には対応していません(YouTubeページのスクリプトから直接データを取れるPC拡張機能側でのみ検討する想定です)。
- 画面キャプチャのサムネイル添付は著作権面の懸念があるため見送っています。
- データは端末のブラウザに保存されるローカルなものです。機種変更やブラウザの データ消去で失われる可能性があるので、大事な記録は「送信用テキストを作成」でこまめに書き出しておくことをおすすめします。

## ファイル構成

```
ytkc-pwa/
├── manifest.json      # PWA設定(share_targetで共有メニューに登録)
├── index.html          # 動画一覧(ホーム画面)
├── share.html           # 共有受け取り・クイック入力画面
├── video.html            # 動画ごとのログ・送信用テキスト作成画面
├── app.js                 # 共通ロジック(保存・URL解析・整形)
├── style.css               # 共通スタイル
├── service-worker.js        # オフライン対応・インストール対応
├── icons/                    # アプリアイコン
└── README.md
```
