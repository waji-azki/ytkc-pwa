# 配信感想メモ (Android向けPWA)

YouTubeのアーカイブを見ながら、再生時刻付きの感想を記録できるWebアプリです。
たまったコメントは、あとでふせったーやDiscordに貼れる形式のテキストにまとめて出力できます。

記録の速さを重視し、メインの使い方は**「同時視聴モード」**です。動画を都度共有する必要はなく、URLを一度貼り付ければ、そのままアプリの中で(または外部再生と連動させて)感想を記録し続けられます。

## できること

### 同時視聴モード(watch.html) — メインの使い方
- URLを貼り付けると、動画とアプリが同時に開始する画面が立ち上がる
- **アプリ内で再生**: YouTubeの埋め込みプレイヤーをアプリ内に表示し、実際の再生位置を自動取得。ズレが起きない、最も正確な方法
- **外部再生+タイマー**: 埋め込みが使えない動画向けの代替手段。「YouTubeで開く」でYouTubeアプリを起動しつつ、アプリ側のストップウォッチを同時にスタート。ピクチャー・イン・ピクチャーや画面分割と組み合わせて使う想定。「-10s/+10s」でいつでも手動補正可能
- 埋め込みが使えない動画(配信者が埋め込みを禁止している場合など)を検出すると、自動で「外部再生+タイマー」に切り替わる
- 絵文字ピッカー・テキスト入力・「コメントなしで位置だけ記録」はどちらのモードでも共通

### 友人の感想をインポート(import.html) — みんなの感想を1つのログで楽しむ
- 友人がこのアプリの「送信用テキストを作成」で出力したテキストを、そのまま貼り付けて取り込める
- 取り込むときに「だれのコメントか」の名前を入力すると、ログ上で色分けされたバッジ付きで表示される(自分のコメントと区別がつく)
- 同じ動画のログに、自分のコメントと友人のコメントが時系列でまとめて並ぶ
- 同じ内容を二重に取り込んでしまわないよう、既に取り込み済みのものは自動でスキップされる
- サーバーを介さず、LINEやDiscordでテキストをやり取りするだけで実現できる仕組み

### 絵文字キーボード
- 😊ボタンでピッカーを開き、タップした絵文字が入力欄に挿入される。ピッカーは自動で閉じないので「😂😂🤣」のように連続で打ってから送信できる(Chrome拡張機能版と同じ挙動)

### 共有経由の記録(share.html)
- YouTubeアプリの共有メニューからもこのアプリを開ける(従来通り)。一度だけサッと記録したいときはこちらでもOK

### そのほか
- 動画ごとに最後の再生位置を自動保存(「前回はここまで視聴」表示、「続きから計測」でwatch.htmlに戻れる)
- 動画ごとのログをチャット風に一覧表示、タイムスタンプをタップでYouTubeの該当時刻にジャンプ
- ログをまとめて送信用テキストに整形し、コピーまたは端末の共有機能でDiscord等に直接渡せる
- データは端末内(localStorage)に保存(PCの拡張機能とは連携しません。今回はAndroid中心の運用という前提です)

## 導入手順(重要:HTTPS配信が必須です)

Web Share Target・YouTube埋め込み・PWAのインストールには、**HTTPSで配信されたページ**である必要があります。`file://`で直接開いても動作しません。

1. このフォルダ一式を GitHub のリポジトリにアップロードする(前回お伝えした手順と同じです。ファイルを更新した場合は、変更したファイルを選んで「Edit」で中身を貼り替えるか、再度アップロードして上書きしてください)
2. リポジトリの Settings → Pages で公開する
3. 発行されたURLにAndroidのChromeでアクセスし、「ホーム画面に追加」でインストールする

## 使い方(同時視聴モード)

1. アプリのトップ画面上部の入力欄にYouTubeのURLを貼り付けて「追加」
2. 「同時視聴で記録」画面が開く。まずは「アプリ内で再生」を試す(デフォルトで選ばれています)
3. 埋め込みプレイヤーの再生ボタンを押して視聴開始。再生位置は自動で記録されるので、あとは😊や入力欄でコメントを打つだけ
4. もし「この動画は埋め込み再生できないようです」と出たら、自動的に「外部再生+タイマー」に切り替わる。「YouTubeで開く」でYouTubeアプリを起動し(ピクチャー・イン・ピクチャーや画面分割にすると見やすい)、「計測開始」ボタンを押すとアプリ側の時計が動き出す
5. 見返したいときはアプリを開いて動画を選ぶと、これまでの感想がログとして並ぶ。「続きから計測」でwatch.htmlに戻れる
6. 「送信用テキストを作成」でふせったー/Discord用にまとめて、コピーまたは共有

## 使い方(友人の感想をインポート)

1. 友人にもこのアプリをインストールしてもらい、同じ動画を見てコメントを記録してもらう
2. 友人に、動画ページの「送信用テキストを作成」でテキストを作ってもらい、LINEやDiscordなどでそのまま送ってもらう
3. 自分のアプリでトップ画面の「📥 友人の感想をインポート」を開き、「だれのコメント?」に友人の名前を入力してテキストを貼り付け、「取り込む」
4. 該当動画のログを開くと、自分のコメントと友人のコメントが色分けされたバッジ付きで一緒に並ぶ
5. これを人数分繰り返せば、複数人の感想を1つのログにまとめて楽しめる

## 現状の制約(正直に書いておきます)

- **「アプリ内で再生」はすべての動画で使えるとは限りません**。配信者が埋め込みを許可していない動画では再生できず、自動的に「外部再生+タイマー」に切り替わります。
- **「外部再生+タイマー」はあくまで概算です**。動画を一時停止・巻き戻し・早送りしても、アプリ側の時計は連動して止まりません。ズレに気づいたら「-10s/+10s」や画面を開き直しての補正が必要です。正確さより速さを優先する前提の機能です。
- アプリ内埋め込み再生は、そのぶん端末のデータ通信量・バッテリーを使います。長時間のTRPGアーカイブなどでは、埋め込みが問題なければ「アプリ内で再生」、通信量やバッテリーが気になる場合は「外部再生+タイマー」で本来のYouTubeアプリを使う、という使い分けもできます。
- 「外部再生+タイマー」でアプリの画面自体を閉じたり再読み込みすると、その時点の計測は止まります(再度「計測開始」を押してください。直前の視聴位置はある程度自動保存されているので、大きくは損なわれません)。
- 字幕の抜粋添付には対応していません(YouTubeページのスクリプトから直接データを取れるPC拡張機能側でのみ対応しています)。
- 画面キャプチャのサムネイル添付は著作権面の懸念があるため見送っています。
- **インポートはリアルタイム同期ではありません**。あくまで「送信用テキストを介した手動の取り込み」です。友人が新しくコメントを追加しても、自動では反映されません。改めてテキストを作ってもらって取り込み直してください。
- 取り込んだログをさらに「送信用テキストを作成」で書き出すと、名前が `(名前) コメント` という形でテキストに含まれます。これを別の人が再度インポートすると、名前表記が二重になることがあります(例: `(ひろき) (たかし) コメント`)。多重転送する場合はご注意ください。
- データは端末のブラウザに保存されるローカルなものです。機種変更やブラウザのデータ消去で失われる可能性があるので、大事な記録は「送信用テキストを作成」でこまめに書き出しておくことをおすすめします。

## ファイル構成

```
ytkc-pwa/
├── manifest.json      # PWA設定(share_targetで共有メニューに登録)
├── index.html          # 動画一覧・URL貼り付け(ホーム画面)
├── watch.html            # 同時視聴モード(埋め込み再生 / 外部再生+タイマー)★メイン画面
├── share.html             # 共有受け取り・クイック入力画面
├── video.html               # 動画ごとのログ・送信用テキスト作成画面
├── import.html               # 友人の送信用テキストを取り込む画面
├── app.js                     # 共通ロジック(保存・URL解析・整形・タイマー状態)
├── style.css                   # 共通スタイル
├── service-worker.js            # オフライン対応・インストール対応
├── icons/                        # アプリアイコン
└── README.md
```
